# 🚗 Site de Locadora de Veículos

Este é um site simples para uma locadora de veículos. Ele mostra os carros disponíveis, informações da empresa e um formulário de contato.

## 🛠️ Tecnologias usadas

- HTML
- CSS


## 📂 Estrutura básica

- `index.html` — Página principal
- `style.css` — Estilos do site
